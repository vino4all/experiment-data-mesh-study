# Hybrid Results

**Evidence status: EXPLORATORY**

These files are retained to document the archived mixed-routing exploration.
The phase executed patterns sequentially and inherited prior state, so it must
not be interpreted as evidence that one architecture is superior under matched
concurrent workloads.

## Files

- `hybrid_comparison.csv`: archived pattern-level latency, throughput,
  freshness, and API-call observations.
- `hybrid_scores.csv`: exploratory weighted score components.
- `pattern_comparison_radar.png`: exploratory comparison figure.
- `pattern_comparison_bar.png`: exploratory score figure.

## Provenance

Generated by `scripts/run-final-validation-experiments.js`, experiment E, after
the prior phases had already mutated shared state.
