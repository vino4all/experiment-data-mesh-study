# Batch Validation Results

**Evidence status: DESCRIPTIVE PRE-CONVERGENCE EVIDENCE; INTERVAL COMPARISON INVALIDATED**

These files are retained for transparency and benchmark-protocol analysis. The
archived runner recorded intended interval labels, but those labels were not
passed to the active batch worker as treatment settings. The data must not be
used as valid interval-comparison evidence.

## Files

- `batch_validation_raw.csv`: archived pre-convergence stale-read observations
  grouped by intended interval label.
- `batch_validation_summary.csv`: descriptive summaries of the archived
  observations.
- `batch_validation_stats.json`: descriptive statistics for the archived
  observations.
- `batch_interval_vs_freshness.png`: retained figure for protocol audit only.

## Provenance

Generated by `scripts/run-final-validation-experiments.js`, experiment A. The
active worker applies `BATCH_SYNC_INTERVAL_MS` at process startup and also
supports explicit `/control/run-once`; the archived interval labels in this
folder did not configure that worker per treatment.
