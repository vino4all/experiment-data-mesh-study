# API Dependency Results

**Evidence status: SUPPORTED DESCRIPTIVE EVIDENCE**

These files report single-run treatment observations for the direct API
dependency experiment. They are suitable for descriptive claims about observed
latency and throughput under injected upstream delay, but they are not repeated
trials.

## Files

- `api_dependency_matrix.csv`: delay, concurrency, request count, latency,
  throughput, and error-rate observations.
- `api_dependency_summary.csv`: delay-level summary statistics.
- `api_delay_vs_orders_latency.png`: latency figure.
- `api_delay_vs_throughput.png`: throughput figure.

## Provenance

Generated by `scripts/run-final-validation-experiments.js`, experiment D,
using the `api-pattern` endpoint and `client-service` failure-injection control.
The values 497 ms, 2159 ms, 345.5 requests/s, and 48.5 requests/s are present in
`api_dependency_matrix.csv` for the 100-concurrency, 30000-request rows at 0 ms
and 2000 ms injected delay.
