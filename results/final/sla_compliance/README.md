# SLA Compliance Results

**Evidence status: INVALIDATED FOR COMPARATIVE CLAIMS**

These files are retained for transparency and benchmark-protocol analysis. The
archived SLA phase reused previously synchronized state and did not generate
matched fresh updates before evaluating each synchronization pattern. Therefore,
these results must not be used to compare SLA compliance across architectures.

## Files

- `sla_compliance.csv`: archived pattern/SLA observations.
- `sla_compliance_by_sla_summary.csv`: archived per-SLA summaries.
- `sla_compliance_summary.csv`: archived pattern summaries.
- `sla_compliance_heatmap.png`: retained figure for protocol audit only.

## Provenance

Generated by `scripts/run-final-validation-experiments.js`, experiment B, using
shared state rather than fresh matched updates per pattern and SLA threshold.
