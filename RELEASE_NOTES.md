# Release Notes - v1.0.0

This release prepares the reproducibility artifact for the accepted IEEE paper
"Experimental Evaluation of Cross-Domain Data Synchronization Architectures
Under Consistency and Failure Constraints."

## Included Evidence

- Supported descriptive API dependency observations.
- Supported ten-trial event-projection recovery validation.
- Archived batch-validation, SLA-compliance, and hybrid artifacts retained with
  explicit limitation labels.

## Important Limitations

- Batch interval comparison is invalidated because intended interval labels were
  not applied to the active worker.
- SLA-compliance results are invalidated for comparative claims.
- Hybrid results are exploratory only.

No DOI is included yet; update `CITATION.cff` when proceedings metadata is
available.
